# Math Quiz PDF

Скилл для решения выбранного варианта из PDF-листка по математике и оформления проверенного LaTeX-PDF.

## Установка

```sh
npx skills add king-of-Jupiter/math-quiz-pdf --skill math-quiz-pdf
```

Для глобальной установки в Codex:

```sh
npx skills add king-of-Jupiter/math-quiz-pdf --skill math-quiz-pdf --agent codex --global
```

## Использование

Прикрепите PDF с заданиями и попросите решить нужный вариант с помощью `math-quiz-pdf`. Скилл уточнит номер варианта перед началом работы.

## Требования

В среде агента должны быть доступны скилл `pdf`, средства LaTeX-рендера и визуальной проверки PDF. Эти инструменты не входят в данный репозиторий и не устанавливаются автоматически.

Исходный SKILL.md опубликован без изменений.
